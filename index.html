MultiGame Assistant 多游戏助手

// 桌面 AGENT · 多游戏日常自动化 DAILY.PIPELINE / 325

「让 agent 替你管好各个游戏的日常脚本」

MultiGameAssistant 是一款 Windows 桌面软件，用 AI agent 替你管好各个游戏的自动化脚本：帮你安装和更新脚本、读懂脚本怎么用，把几个游戏的日常排成每天定时自动运行的流水线；运行中出错或卡住，先自己处理，处理不了再由 agent 看画面动手排查；它还会整理各游戏的活动和你的进度，最后通过飞书把结果告诉你。

「不绑定某个游戏、某个脚本或某家模型——你用什么，它就管什么。」

  • 任意脚本
  • 任意游戏
  • 任意模型
  • Windows 10 / 11 · x64 / ARM64
