MultiGame Assistant

你去上班上课，日常交给它。

它不是又一个脚本，而是管脚本的一组 agent：助手和你说话、派活，干预、游戏、脚本、编排各管一摊。替你装脚本、读懂脚本，把几个游戏的日常排成每天定时运行的流水线；出了问题自己查、自己修，最后通过飞书或 QQ 把结果告诉你。

  • 任意脚本
  • 任意游戏
  • 任意模型

02 / 04

日常

A DAY · 08:30 → 12:30

DEMO // SCRIPTS
08:30[REC]
界面演示动画：随页面滚动依次展示脚本、流水线编排、运行监控、飞书和 QQ、助手派活与技能和游戏信息。

  1. 08:30出门前

    脚本早已各就各位

    明日方舟的基建还没换班，星穹铁道的体力快溢出了，终末地的活动还剩两天。没关系，脚本都装好、配好了。

    • 一键安装从 GitHub 或 Mirror酱 安装，断点续传、校验、补齐运行环境；运行前先走正式渠道更新，也能回滚、删除。
    • 导入本地脚本不移动、不修改原目录，自动认出版本和更新渠道。
    • 任意脚本没见过的脚本，「脚本」agent 先读项目文档再看代码，写成「脚本包」草稿给你确认。
    • 配置副本大号、小号各存一份配置，原项目里的设置不受影响。

  2. 09:00编排与定时

    上班上课，它按时开工

    把几个游戏的日常连成一张流水线，设成「工作日 09:00」，剩下的就不用管了。

    • 流水线画布并行、排队、失败重试、agent 步骤、人工确认，拖到画布上连线即可。
    • 等问题处理完前一步出的问题还没解决，后面的步骤不会自己开始。
    • 无人值守开机自启、定时唤醒、错过了在宽限时间内补跑，跑完关游戏、关模拟器或关机。
    • 用说的也行「帮我把这几个脚本排成每天早上跑的流程」，「编排」agent 起草一份给你确认。

  3. 10:20监控与干预

    出了问题，它自己查、自己修

    脚本最怕的不是报错，而是卡住没人管。

    • 卡住检测默认 1 分钟没有新日志算卡住；每个脚本会从自己跑成功的记录里学会正常时要安静多久。
    • 先自动处理出错、卡住、超时，按脚本包里写好的办法重跑、等待或重启模拟器。
    • 再交给干预「干预」agent 先确认还需不需要处理，再截图看画面（报错框被别的窗口挡住也看得到），点击、输入排除后让脚本接着跑。
    • 全程留痕每一步都有记录，结果回到助手的对话，并推送到飞书和 QQ。

  4. 10:50飞书 · QQ

    手机一句话，远程指挥电脑

    接入飞书或 QQ 机器人，在手机上跟助手聊，就像坐在电脑前。

    • 直接说想做的事「现在什么状态？」「把明日方舟的日常跑一下。」
    • 点一下就回答飞书卡片、QQ 按钮直接回答通知、审批和提问；提问和审批发给最后说话的那个人。
    • 同一个对话软件、飞书、QQ 里看到的是同一份；收到的是这一轮的总结，不会把每个步骤都发一遍。
    • 每日日报定时发到手机，只挑近期的事来总结；提醒也算进这个对话。

  5. 10:58Agent 与技能

    助手派活，跑稳了还能再优化

    左边是 agent 名册：你只和助手说话，它把活交给干预、游戏、脚本、编排，做完的结果作为一条消息回到它的对话。

    • 各管一摊角色 agent 只看得到自己用得上的工具；可以单独选一个便宜、能看图的模型，省用量。
    • 优化脚本跑成功 5 次或更新后第一次跑通，它会问要不要优化：重新总结脚本包、调卡住时间、把走通的步骤存成技能。
    • 技能按游戏分每个游戏一节，先放游戏的，再放各脚本的，最后是通用技能；可以自己新建、编辑、删除。
    • 斜杠命令输入 / 调出命令和技能，按「游戏 · 脚本」分组；/优化脚本 脚本名 直接开始。

  6. 12:30游戏信息

    所有游戏的活动，一眼看完

    玩的游戏一多，最容易漏的就是限时活动。

    • 同一条时间轴还剩几天、哪些快结束了还没做完，全部排在一起。
    • 进游戏看进度「游戏」agent 进游戏看你的实际进度，标成做完、做了一部分或需要关注。
    • 数据不花模型调用SRA 公共 API、PRTS、B 站游戏 WIKI 每天自动读；官网公告和你添加的网址由 agent 去读。
    • 更多游戏SRA 公共 API 支持的 18 个游戏直接关注；其他游戏，agent 去找 Wiki 和官网。

演示由软件的真实前端代码驱动，数据为演示快照，不连接真实账号。脚本本身来自各自的开源项目，本软件负责安装、配置、调度和看护，不修改脚本的代码。

04 / 04

安全与问答

SAFETY · FAQ

  • PERMISSION你说了算的权限

    默认「每次确认」：agent 的命令在沙箱里运行，安装陌生仓库、操作屏幕、修改脚本文件等都先问你；也可以按范围一项项设成允许、先问我或不允许。

  • HANDS OFF不动原脚本

    只负责安装、配置、调度和看护，不修改游戏文件，也不修改脚本的代码；运行时用的是单独保存的配置。

  • OPEN SOURCE开源，模型自选

    以 AGPL-3.0 开源，代码都在 GitHub 上；用哪家模型由你决定，也可以用本机的 Ollama。

风险提示

使用自动化程序可能违反相关游戏的用户协议，账号有被警告、限制或封禁的风险。请在了解风险的前提下酌情使用，由此产生的后果由使用者自行承担。

需要自己的模型 API key 吗？

需要。装好后在软件里选模型、填 API key；不想用云端模型，也可以接本机的 Ollama。

不接飞书或 QQ 能用吗？

能。飞书和 QQ 用来接收通知、日报和确认，以及在手机上和助手对话；不接的话，在软件里看运行记录、和助手对话即可。

agent 会乱动我的电脑吗？

默认是「每次确认」：命令在沙箱里运行，敏感操作先问你。出问题时「干预」能不能动手也可以单独设置：诊断并处理、只诊断或不干预。

这么多 agent，会多花很多模型用量吗？

角色 agent 只在有活时才干，看得到的工具也少。可以在「设置 → 模型 → 角色 agent 的模型」里给它们选一个便宜、能看图的模型。

我已经在用的脚本要重新装吗？

不用。在脚本页点「导入本地项目」，不移动、不复制、不修改原目录；能认出版本的脚本以后还能直接检查更新。

电脑是 ARM 处理器，装哪个？

骁龙等 ARM 处理器的电脑选 Windows ARM64。下载按钮会自动识别，也可以手动切换；该版本没有 ARM64 包时会提示并回退到 x64。

已经装了 dsh，还要装完整安装包吗？

不用，装成 dsh 插件就行，见「版本发布」页的「dsh 插件」。插件版没有托盘、开机自启和定时唤醒。

支持 macOS 或 Linux 吗？

目前只支持 Windows 10 / 11（x64 和 ARM64）。
