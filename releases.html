02安装与更新

SETUP // 安装包

双击安装

x64 选 MultiGameAssistant-Setup-<版本>.exe，ARM64 选 …-arm64.exe。装在当前用户下，不需要管理员；支持 /S 静默安装。

更新软件内会提示新版本，一键下载并安装；也可以在这里下载新安装包覆盖安装。

POWERSHELL // 一行命令

自动选包、校验、静默安装

irm https://raw.githubusercontent.com/haaahhhis/MultiGameAssistant/main/scripts/install.ps1 | iex

更新再运行一次同一条命令，设置和数据都保留。GitHub 下载慢时先设置 $env:MGA_MIRROR='https://ghproxy.net/'。

DSH PLUGIN // 插件包

已经装了 dsh

dsh --profile mga --from-default-profile web --help dsh plugin --profile mga add https://github.com/haaahhhis/MultiGameAssistant/releases/download/v<版本>/dsh-multigameassistant-<版本>.tgz dsh mga --no-open

更新用新版本的链接再 add 一次。第一行只在第一次运行；插件版没有托盘、开机自启和定时唤醒。
